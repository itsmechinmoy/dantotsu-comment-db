Introduction #

Dantotsu Comment DB is a unified, shared community discussion service built for anime and manga applications. Comments and reply threads are indexed directly by AniList Media IDs, allowing users across different clients to interact, post episode or chapter discussions, vote, and receive reply notifications.

Platform Architecture #

The service operates over standard HTTP with form-encoded mutation payloads and JSON responses. Every comment receives a globally unique, sequential integer comment_id across all media. User authentication is verified cryptographically using legitimate AniList OAuth credentials, ensuring user identity consistency and spam resistance across the ecosystem.

Commenting Rules #

Any third-party client integrating Dantotsu Comment DB must make users aware of and enforce the 10 community rules before allowing submissions. Moderation applies universally across the entire database.

Rules Enforcement Policy

Violating any of the rules below will lead to immediate comment removal. Serious or repeat infractions will result in a permanent ban of the user ID and connected AniList credentials.

  1. No racism, discrimination, or hate speech — Zero tolerance for discrimination based on race, ethnicity, religion, gender, or orientation.
  2. No spamming or self-promotion — Prohibited duplicate messages, automated bot submissions, referral links, or advertising.
  3. Absolutely no NSFW content — Explicit, pornographic, sexually graphic, or gore material is strictly forbidden.
  4. English only – no exceptions — All publicly posted comments must be written in English to ensure transparent moderation.
  5. No impersonation, harassment, or abuse — Harassment, targeted hostility, or pretending to be team members is prohibited.
  6. No illegal content or extreme disrespect towards any fandom — Discussions must remain civil and conform to applicable laws.
  7. Do not request or share repositories or extensions — Conversations must remain focused on the media itself, not extension piracy or repo links.
  8. Spoilers allowed only with spoiler tags and a warning — Spoilers must be enclosed within tags (~!spoiler text!~ or ||spoiler text||) and clearly prefixed with a warning.
  9. No sexualizing or inappropriate comments about minor characters — Results in immediate permanent ban without appeal.
  10. If it's wrong, don't post it! — Maintain common decency and appropriate conduct.

Universal Headers #

All requests dispatched to https://api.dantotsu.app require the client application handshake header. Authenticated requests also include the authorization session key.

Header Value Requirement
appauth 6*45Qp%W2RS@t38jkXoSKY588Ynj%n Required on every request
Authorization <authToken> Required for mutations, voting, profile & notifications

Authorization Format & Data Types

Pass the raw token string directly in the Authorization header without any Bearer prefix. Note that boolean values in responses (such as is_banned, is_mod, is_admin, and deleted) are returned as integers: 1 for true and 0 for false.

Authentication #

To authenticate, exchange a valid AniList OAuth access token with the authentication endpoint. Issued tokens remain valid for approximately 6 days.

Exchange AniList Token

POST https://api.dantotsu.app/authenticate

bash 
curl -X POST "https://api.dantotsu.app/authenticate" \
  -H "appauth: 6*45Qp%W2RS@t38jkXoSKY588Ynj%n" \
  -d "token=ANILIST_OAUTH_TOKEN"

Response (200 OK)

json 
{
  "authToken": "eyJhbGciOi...",
  "user": {
    "user_id": "123456",
    "username": "ErenJaeger",
    "profile_picture_url": "https://s4.anilist.co/file/anilistcdn/user/avatar/...",
    "is_banned": 0,
    "is_mod": 0,
    "is_admin": 0,
    "total_votes": 12,
    "warnings": 0
  }
}

Data Models #

Comment Object

The standard comment schema returned by comments listings, reply threads, and single-comment queries:

Field Type Description
comment_id integer Unique sequential ID assigned to the comment.
user_id string AniList User ID of the author.
media_id integer AniList Media ID of the anime or manga.
parent_comment_id integer | null Target comment ID if this is a thread reply, or null if top-level.
content string Markdown body text. If deleted, this contains [deleted].
timestamp string ISO-8601 formatted publication timestamp.
deleted integer 1 if deleted by author or moderation, otherwise 0.
tag integer | null Episode or chapter index number, or null.
upvotes integer Total positive votes received.
downvotes integer Total negative votes received.
user_vote_type integer | null Current user's vote state: 1 (upvote), -1 (downvote), or 0 / null (neutral).
username string Author username (may also appear under user.username).
profile_picture_url string | null Avatar URL (may also appear under user.profile_picture_url).
is_mod integer 1 if author is a moderator, otherwise 0.
is_admin integer 1 if author is an administrator, otherwise 0.
reply_count integer Total direct replies posted under this comment.
total_votes integer Cumulative author voting karma.

API Reference #

Fetch Media Comments

GET https://api.dantotsu.app/comments/:media_id/:page

Retrieves paginated comments for an AniList media item. When all available pages have been consumed, comments returns an empty array [].

Parameter Type In Description
media_id integer Path AniList Media ID (e.g. 16498)
page integer Path Page number (starts at 1)
tag integer Query Optional episode or chapter number filter (e.g. ?tag=1)
sort string Query newest, oldest, highest_rated, or lowest_rated
json 
{
  "comments": [
    {
      "comment_id": 48210,
      "user_id": "123456",
      "media_id": 16498,
      "parent_comment_id": null,
      "content": "Incredible production value on this episode.",
      "timestamp": "2024-03-20T14:32:00.000Z",
      "deleted": 0,
      "tag": 1,
      "upvotes": 45,
      "downvotes": 2,
      "user_vote_type": 1,
      "username": "ErenJaeger",
      "profile_picture_url": "https://...",
      "is_mod": 0,
      "is_admin": 0,
      "reply_count": 3,
      "total_votes": 43
    }
  ],
  "totalPages": 5
}

Fetch Thread Replies

GET https://api.dantotsu.app/comments/parent/:parent_comment_id/:page

Returns paginated replies submitted under a specified root comment.

Fetch Single Comment

GET https://api.dantotsu.app/comments/:comment_id

Fetches a single comment by its unique sequential comment_id. Returns 200 OK with the comment object, or 404 Not Found if nonexistent.

Current User Profile

GET https://api.dantotsu.app/user

Validates session credentials and retrieves current user permissions, ban state, warnings count, and total karma votes.

Post Comment or Reply

POST https://api.dantotsu.app/comments

Submits a new top-level comment or threaded reply. Requires authentication.

Field Type Required Description
user_id string Yes User ID from authentication
media_id integer Yes AniList Media ID
content string Yes Markdown body text (supports ~!spoiler!~ syntax)
tag integer No Episode or chapter index tag
parent_comment_id integer No Target comment ID if creating a reply

Vote on Comment

POST https://api.dantotsu.app/comments/vote/:comment_id/:vote_type

Casts or clears an upvote or downvote for the authenticated user.

vote_type Description
1 Upvote comment
-1 Downvote comment
0 Remove existing vote / reset to neutral

Edit & Delete

PUT https://api.dantotsu.app/comments/:comment_id

Updates comment body with form-encoded field content.

DELETE https://api.dantotsu.app/comments/:comment_id

Soft-deletes the comment, masking the contents to [deleted] in feeds.

Report Violation

POST https://api.dantotsu.app/report/:comment_id

Dispatches a violation report to community moderators with form fields: username, mediaName, reporter, and reportedId.

Notifications

GET https://api.dantotsu.app/notification/reply

Returns pending notifications when other members reply to the user's comments.

Rate Limiting & Best Practices #

To maintain API stability, rate limits are enforced across endpoints:

  • HTTP 429 Status: If too many requests are sent in a short window, the server responds with 429 Too Many Requests. Clients should wait 30 seconds before retrying.
  • Throttling: When performing consecutive queries or iterating through pages, include a delay of at least 150ms–200ms between requests.
  • Timeouts: Set HTTP client read timeouts to 15–30 seconds to handle intermittent high load gracefully.
  • Token Caching: Cache the authToken locally for its 6-day lifetime and re-verify using GET /user on application launch rather than calling /authenticate repeatedly.

Client Implementation #

The complete, typed TypeScript client below can be copied directly as a single file into any application.

ts 
/**
 * Dantotsu Comments API Client
 * Single-file implementation for Web, React Native, and Node.js.
 */

export interface DantotsuComment {
  comment_id: number;
  user_id: string;
  media_id: number;
  parent_comment_id: number | null;
  content: string;
  timestamp: string;
  deleted: number;
  tag: number | null;
  upvotes: number;
  downvotes: number;
  user_vote_type: number | null;
  username: string;
  profile_picture_url: string | null;
  is_mod?: number;
  is_admin?: number;
  reply_count?: number;
  total_votes: number;
}

export interface DantotsuUser {
  user_id: string;
  username: string;
  profile_picture_url: string | null;
  is_banned?: number;
  is_mod?: number;
  is_admin?: number;
  total_votes: number;
  warnings: number;
}

export class DantotsuCommentsClient {
  private readonly baseUrl = "https://api.dantotsu.app";
  private readonly appAuthKey = "6*45Qp%W2RS@t38jkXoSKY588Ynj%n";
  public authToken: string | null = null;
  public currentUser: DantotsuUser | null = null;

  private getHeaders(): Record<string, string> {
    const headers: Record<string, string> = {
      appauth: this.appAuthKey,
    };
    if (this.authToken) {
      headers["Authorization"] = this.authToken;
    }
    return headers;
  }

  /** Authenticate using an AniList OAuth access token */
  async authenticate(anilistToken: string): Promise<DantotsuUser> {
    const body = new URLSearchParams({ token: anilistToken });
    const res = await fetch(`${this.baseUrl}/authenticate`, {
      method: "POST",
      headers: this.getHeaders(),
      body,
    });
    if (!res.ok) throw new Error(`Authentication failed with status ${res.status}`);
    const data = await res.json();
    this.authToken = data.authToken;
    this.currentUser = data.user;
    return data.user;
  }

  /** Retrieve the current authenticated user's profile */
  async getUser(): Promise<DantotsuUser> {
    const res = await fetch(`${this.baseUrl}/user`, {
      headers: this.getHeaders(),
    });
    if (!res.ok) throw new Error("Failed to fetch user profile");
    const data = await res.json();
    this.currentUser = data.user;
    return data.user;
  }

  /** Retrieve comments for an AniList media item */
  async getComments(
    mediaId: number,
    page: number = 1,
    options?: { tag?: number; sort?: "newest" | "oldest" | "highest_rated" | "lowest_rated" }
  ): Promise<{ comments: DantotsuComment[]; totalPages: number }> {
    const params = new URLSearchParams();
    if (options?.tag !== undefined) params.set("tag", options.tag.toString());
    if (options?.sort) params.set("sort", options.sort);
    const query = params.toString() ? `?${params.toString()}` : "";

    const res = await fetch(`${this.baseUrl}/comments/${mediaId}/${page}${query}`, {
      headers: this.getHeaders(),
    });
    if (!res.ok) throw new Error("Failed to fetch comments");
    return res.json();
  }

  /** Retrieve replies for a specific parent comment */
  async getReplies(
    parentId: number,
    page: number = 1
  ): Promise<{ comments: DantotsuComment[]; totalPages: number }> {
    const res = await fetch(`${this.baseUrl}/comments/parent/${parentId}/${page}`, {
      headers: this.getHeaders(),
    });
    if (!res.ok) throw new Error("Failed to fetch replies");
    return res.json();
  }

  /** Fetch an individual comment by its sequential comment_id */
  async getSingleComment(commentId: number): Promise<DantotsuComment | null> {
    const res = await fetch(`${this.baseUrl}/comments/${commentId}`, {
      headers: this.getHeaders(),
    });
    if (res.status === 404) return null;
    if (!res.ok) throw new Error("Failed to fetch comment");
    return res.json();
  }

  /** Create a new comment or reply */
  async postComment(
    mediaId: number,
    content: string,
    tag?: number,
    parentCommentId?: number
  ): Promise<any> {
    if (!this.currentUser) throw new Error("User must be authenticated to comment");
    const body = new URLSearchParams({
      user_id: this.currentUser.user_id,
      media_id: mediaId.toString(),
      content,
    });
    if (tag !== undefined) body.set("tag", tag.toString());
    if (parentCommentId !== undefined) body.set("parent_comment_id", parentCommentId.toString());

    const res = await fetch(`${this.baseUrl}/comments`, {
      method: "POST",
      headers: this.getHeaders(),
      body,
    });
    if (!res.ok) throw new Error("Failed to post comment");
    return res.json();
  }

  /** Vote on comment: 1 = upvote, -1 = downvote, 0 = reset */
  async vote(commentId: number, voteType: 1 | -1 | 0): Promise<boolean> {
    const res = await fetch(`${this.baseUrl}/comments/vote/${commentId}/${voteType}`, {
      method: "POST",
      headers: this.getHeaders(),
    });
    return res.ok;
  }

  /** Edit comment */
  async editComment(commentId: number, content: string): Promise<boolean> {
    const body = new URLSearchParams({ content });
    const res = await fetch(`${this.baseUrl}/comments/${commentId}`, {
      method: "PUT",
      headers: this.getHeaders(),
      body,
    });
    return res.ok;
  }

  /** Delete comment */
  async deleteComment(commentId: number): Promise<boolean> {
    const res = await fetch(`${this.baseUrl}/comments/${commentId}`, {
      method: "DELETE",
      headers: this.getHeaders(),
    });
    return res.ok;
  }

  /** Report rule violation */
  async reportComment(commentId: number, username: string, mediaName: string, reportedId: string): Promise<boolean> {
    const body = new URLSearchParams({
      username,
      mediaName,
      reporter: this.currentUser?.username || "unknown",
      reportedId,
    });
    const res = await fetch(`${this.baseUrl}/report/${commentId}`, {
      method: "POST",
      headers: this.getHeaders(),
      body,
    });
    return res.ok;
  }

  /** Fetch reply notifications */
  async getNotifications(): Promise<any> {
    const res = await fetch(`${this.baseUrl}/notification/reply`, {
      headers: this.getHeaders(),
    });
    if (!res.ok) throw new Error("Failed to fetch notifications");
    return res.json();
  }
}
